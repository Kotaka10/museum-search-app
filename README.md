## ◆アプリ概要

全国の美術館・博物館・写真・庭園を検索・登録できるアプリです。フリーワードおよび都道府県別に検索できます。  
また、現在地から半径50km以内の美術館等を検索できます。

## ◆主要機能

### 美術館等に関する機能
- フリーワード検索
- 都道府県ごとに検索
- 美術館/博物館/庭園/写真ごとに検索
- マップ（有効範囲半径50km以内）検索
- スタックカードスライド
- 自動カルーセル（美術館の施設画像が自動でスライドされるUI）
- 手動カルーセル（ユーザーが展覧会画像を操作してスライドさせるUI）
- 検索結果のソート機能（開催日が近い順・終了日が近い順）
- 閲覧履歴

### ユーザーに関する機能
- 会員登録/ログイン
- 会員情報（プロフィール画像/パスワード/ユーザー名/メールアドレス）の変更・保存
- 展覧会へのコメント投稿/一覧表示/編集/削除
- 美術館等施設の登録/一覧・詳細表示/編集/削除

### その他
- レスポンシブデザイン
- ISR/SSG

## 工夫した点・技術的チャレンジ
1. Topページの画像を使用した4種類のUI開発  
   美術館/博物館/庭園・写真の展覧会に応じたスタックカードスライドUI（スマホ・タブレット）や手動カルーセルUIなどアプリをユーザーが直感的に操作できるUIを取り入れており、楽しんでもらえるように工夫しました。

2. スマホ・PCに応じたUIの選択  
   スマホ版とPC版で一部UIを変更しており、環境に適したUI構成としています。
   
3. 検索の利便性   
   フリーワード検索・現在地周辺のマップ検索・都道府県別検索・施設別検索と4種類の検索方法を取り入れることにより、目的の展覧会をより快適に検索できます。
   
4. シンプルな構成による見やすい情報  
   美術館詳細ページをシンプルで見やすい構成にしているため気になる展覧会の情報を見やすくしています。
