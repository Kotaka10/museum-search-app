**アプリ概要**
全国の美術館・博物館・写真・庭園を検索・登録できるアプリです。フリーワードおよび都道府県別に検索できます。また、現在地から半径50km以内の美術館等を検索できます。

**使用技術**

**フロントエンド**
- Tailwind CSS
- Javascript
- React
- Next.js

**バックエンド/データベース**
- Java 21
- Spring Boot 3.5.4
- MySQL

**デプロイ / ホスティング**
- Vercel (フロントエンド)
- Render (バックエンド)

**主要機能**
- 検索・登録に関する機能
・フリーワード検索
・都道府県ごとに検索
・美術館/博物館/庭園/写真ごとに検索
・マップ（有効範囲半径50km以内）検索
・スタックカードスライド
・自動カルーセル（美術館の施設画像が自動でスライドされるUI）
・手動カルーセル（ユーザーが展覧会画像を操作してスライドさせるUI）
・検索結果のソート機能（
・美術館等施設の登録/一覧・詳細表示/編集/削除
